# Долги — трекер займов

Личный учёт денег, которые я одолжил или занял. По каждому человеку видно, сколько он должен и сколько процентов уже набежало.

Одно одностраничное приложение: работает в браузере, ставится на телефон как обычное приложение и открывается без интернета.

**Открыть:** `https://ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/` — замените на свой адрес после публикации.

## Что умеет

- **Один человек — сколько угодно займов.** У каждого займа своя сумма, валюта, ставка, даты, статус и платежи.
- **Проценты считаются сами**: годовые, месячные, дневные (процент в день), фиксированная сумма или без процентов.
- **Итоги по человеку**: остаток долга, начисленные проценты, сумма к оплате, просрочка и позиция — «должны мне» или «я должен».
- **Общий экран**: суммы к получению, к возврату, баланс и проценты; список людей по сумме долга.
- **Платёж** пересчитывает заём сразу, а форма займа показывает итог до сохранения.
- **Продление**: закрывает старый заём платежом на сумму остатка и переносит остаток в новый заём с новыми процентами. Ничего не списывается.
- **Просрочка** подсвечивается, есть необязательная пеня (ставка задаётся в настройках).
- **Две темы** (светлая и тёмная) и два языка — русский и английский, переключатель `RU`/`EN` в шапке.

## Как поставить на телефон

**Android (Chrome):** откройте адрес → меню ⋮ → **«Установить приложение»** (или «Добавить на главный экран»).

**iPhone / iPad (Safari):** откройте адрес → кнопка **«Поделиться»** → **«На экран „Домой“»**. Именно Safari: в других браузерах на iOS этого пункта нет.

После установки приложение открывается без адресной строки, на весь экран, и запускается без сети.

## Где хранятся данные

Только в `localStorage` вашего браузера, на вашем устройстве. Никакого сервера, аккаунта и отправки данных нет. Очистка данных сайта в браузере удалит всё, поэтому важные записи стоит дублировать.

## Как это сделано

- `index.html` — всё приложение в одном файле: интерфейс, расчёты, стили, словари и демо-данные.
- `manifest.webmanifest` — чтобы телефон считал это устанавливаемым приложением.
- `sw.js` — офлайн-кеш: после первого открытия страница доступна без сети.
- `icons/` — иконки для Android, iOS и вкладки браузера.

Проценты — простые, на исходную сумму долга, без капитализации. Формула:
`долг × ставка / 100 × дней / база периода`, где база 365 для годовых, 30 для месячных и 1 для дневных.
